# mushi-scope

iPhone / Android のマイクに届く鳴く虫の声を、端末内でリアルタイムに簡易分析・可視化する静的 Web アプリです。

## 現在の実装範囲

- 利用者操作によるマイク許可と解析開始 / 停止
- Web Audio API によるモノラル入力、低域抑制、FFT
- 5種の代表周波数帯 + 「不明」の複数候補表示
- 推定相対音量を 18〜64px の文字サイズへ変換
- 判定確信度を透明度へ変換
- 移動平均、検出保持、フェードアウトによる表示安定化
- 音声データを送信しないブラウザ内処理

現時点では学習済み AI モデルを使用せず、仕様書で MVP の開始方法として認められている代表周波数帯による簡易推定です。種レベルの正確な同定を保証するものではありません。

## 起動

マイク利用には `localhost` または HTTPS が必要です。任意の静的 HTTP サーバーでこのフォルダを配信してください。

```powershell
python -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。
