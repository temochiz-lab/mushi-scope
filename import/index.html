IMPORT / PC

画像から、
判別データを育てる。

iPhoneで保存した学習PNGをまとめて読み込み、破損を検査して虫別の判別プロファイルを生成します。処理はPCブラウザ内で完結します。

1. 学習PNGを読み込む

元の1024×1024 PNGを選択してください。リサイズやJPEG変換された画像は読み込めません。

2. 内容を確認

虫名と録音日時を確認し、必要なら音声を再生してからプロファイルを作成してください。

    3. 判別プロファイルを作成

    虫名ごとに複数録音の特徴を統合し、リアルタイム判別アプリが読み込むJSONを作ります。

    ダウンロードしたファイルを data/profiles/insect-profiles-v1.json としてリポジトリへ配置してください。
